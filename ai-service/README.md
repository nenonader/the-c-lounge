# The C Lounge — Private Concierge AI service (v72)

Made By Eng Nayer Nader

FastAPI service that runs the concierge. Only the Node backend talks to it,
authenticated with `SERVICE_API_KEY`. Nothing here is exposed to a browser.

## Run locally

    pip install -r requirements.txt
    uvicorn app.main:app --reload --port 8001

## Test

    python -m pytest tests -q
    python tests/test_v72_regressions.py   # no pytest needed

## Endpoints

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| GET | `/health` | none | Liveness, engine status, `claude_share` |
| GET | `/api/chat/suggestions` | service key | Opening prompts |
| POST | `/api/chat/stream` | service key | The visitor turn (NDJSON) |
| POST | `/api/route` | service key | Desk routing controller |
| POST | `/admin/diagnose` | admin key | One real call per model; names the cause |
| GET | `/admin/turns` | admin key | Recent per-turn telemetry |

## The number that matters

`/health` returns `claude_share`. **1.0 means every turn was generated by
Claude.** Anything lower means real visitors received the holding reply, and
`/admin/diagnose` will tell you why in one request.

## Module map

| File | Role |
| --- | --- |
| `config.py` | Environment-driven configuration |
| `knowledge.py` | Authoritative C Lounge facts, transcribed from the live site |
| `persona.py` | System prompt and the JSON turn contract |
| `brain.py` | Anthropic client, model fallback chain, envelope validation |
| `security.py` | Scored injection scan, prompt canary, output adjudication |
| `state.py` | Session store, seed extraction, honest fallback |
| `telemetry.py` | Per-turn ring buffer and counters |
| `main.py` | Endpoints and the turn flow |

## Design rule

The model is an untrusted text generator. Nothing it produces reaches a visitor
without passing `security.output_verdict()`. Nothing a visitor writes is ever an
instruction.
